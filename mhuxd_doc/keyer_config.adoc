=== Menu Keyer Mode
This menu is available for DIGI KEYER II, micro KEYER, micro KEYER II, micro KEYER III, MK2R and MK2R+. The MK2R(+) has a section for each radio.

* *Keyer Mode Follows RIG* – Not available for the micro KEYER. With this option enabled the keyer sets the keyer mode according to the rig mode. For this to work you must have configured the rig type and serial parameters in the “Radio Menu”. Additionally the option “Use Decoder if Connected” must be enabled there. RIG Mode Sync (see <<rig_mode_sync>>) works without it.
* *Current Mode* – This shows the current keyer mode (CW, VOICE, FSK, DIGITAL) and allows to change it.

Like the microHam Router, mhuxd doesn't choose the keyer mode of the CW KEYER and the DIGI KEYER: the CW KEYER works in CW, the DIGI KEYER in DIGITAL.

=== Menu Radio
This menu is not available for CW KEYER. This page allows to configure the serial parameters between the keyer and the transceiver:

* Baud Rate
* Data Bits
* Stop Bits
* RTS/CTS Handshake

Refer to your transceivers manual on how to set these parameters. The MK2R(+) has a section for each radio.

For DIGI KEYER II, micro KEYER II, micro KEYER III, MK2R(+) and Station Master additional options are available. These options affect the keyers capability to send CAT commands to the rig on its own:

* *Rig Type:* Select your rig. This tells the keyers internal CAT decoder which rig is attached. If it is an Icom the selection will autofill the Icom Address field. You may choose “none” here which will reliably disable CAT queries from the keyer. RIG Mode Sync with backend native uses the rig type too.
* *Icom Address:* If you use an Icom rig this field must contain the Icom address in decimal notation. Usually this field gets auto filled from the Rig Type selection.
* *PW1 Connected:* Select this option if you have an Icom PW1 amplifier connected to the same bus as the rig. When enabled the keyer will periodically generate “auto-info”, preventing queries (and possible collisions) by PW1.
* *Digital Over Voice:* Choose how LSB, USB and FM modes are interpreted:
** *Band Map* – set keyer mode according to band map
** *Always VOICE* – set keyer mode always to VOICE
** *Always DIGITAL* – set keyer mode always to DIGITAL
* *Use Decoder if Connected:* Select this to enable the keyers CAT decoder even when the keyer is USB connected to a computer.
The CAT decoder is used to synchronize the keyers mode with the rig mode. If disabled the keyer mode must be selected in the WebUI or by an application.
The decoder is always active when the keyer is not USB connected to a computer.
[red]#Enabling this may lead to interference. That is, CAT requests from the keyer colliding with CAT requests from an application like WSJT-X. RIG Mode Sync offers a more stable solution to provide the keyer with the current mode and frequency, see <<rig_mode_sync>>.#
* *Don’t Interfere USB control:* Disable CAT queries by the keyer if it is USB connected to a computer. Only answers to the computer will be interpreted.
This works with the older Yaesu radios (checked with a DIGI KEYER II and an FT-1000MP), but [red]#not with Icom: with an Icom rig selected the keyer polls anyway# (DIGI KEYER II, IC-7300), probably to keep CI-V accessories like the PW1 informed.

The lower part of the page holds the sections *RIG Mode Sync* and *rigctld*, see <<rig_mode_sync>>.

=== Menu AUX
This menu is only available for keyers with an AUX port (micro KEYER II, micro KEYER III, Station Master). Allows to specify the serial parameters of the AUX port.

=== Menu FSK
This menu is only available for keyers with an FSK channel (all but the CW KEYER and the Station Master). It configures the serial parameters of the FSK channel, the MK2R(+) has one for each radio. Refer to the original microHam documentation for your keyer.

* *Invert FSK* – invert the FSK keying signal
* *Pseudo FSK* – DIGI KEYER II and micro KEYER III only: the keyer keys its FSK output from an on/off keyed tone in the right sound card channel, e.g. fldigi's “pseudo-FSK”. Refer to the keyer manual.

=== Menu PTT
This page allows the configuration of the PTT operation. The available options vary between keyer types; the MK2R(+) has a section for each radio.

NOTE: This is a very basic overview. Please refer also to the original microHam documentation for your keyer.

* *PTT CW* – Select the PTT output for CW mode
* *PTT Voice* – Select the PTT output for VOICE mode
* *PTT Digital* – Select the PTT output for DIGITAL mode
* *LNA PTT* – Enable LNA PTT relay
* *PA PTT* – Enable PA PTT relay
* *PA PTT Tail (x 10ms)* – PA PTT Tail time
* *LNA PTT Tail (x 10ms)* – LNA PTT Tail time
* *PTT Lead (x 10ms)* – PTT Lead time
* *CW in Voice* – Allow CW operation in VOICE mode (micro KEYER II/III, MK2R(+) only)
* *Sound Card PTT* – key PTT when soundcard produces audio (DIGI KEYER II, micro KEYER II/III only)
* *Downstream over Footswitch* – when soundcard produces audio the audio source will be switched from microphone to sound card, even if the foot switch is pressed (untested, DIGI KEYER II, micro KEYER II/III only)

The PTT outputs offered:

[cols="2,1,1,1"]
|===
| Keyer | CW | Voice | Digital

| CW KEYER        | PTT, QSK | – | –
| DIGI KEYER      | – | – | PTT, No PTT
| DIGI KEYER II   | PTT, QSK, Semi Break-in | – | –
| micro KEYER     | PTT1, QSK, PTT2 | PTT1, PTT2 | PTT1, PTT2, PTT1+2
| micro KEYER II/III, MK2R(+) | PTT1, QSK, Semi Break-in, PTT2 | PTT1, PTT2 | PTT1, PTT2, PTT1+2
|===

PTT1 is the PTT line of the mic jack, PTT2 the one on the rear panel jack.

==== Footswitch Sequencer
Additional functions for the footswitch (or the PTT of a hand microphone):

* *Mute serial CW* – mute CW from an application (DTR or RTS) while the footswitch is pressed.
* *Mute serial FSK* – block the FSK ports while the footswitch is pressed.
* *Restore serial PTT and audio* – when the footswitch is released, restore the application's PTT and the audio routing for it. Otherwise this only happens after the application has released PTT.
* *Restore serial CW* – resume the application's CW when the footswitch is released (if it has not ended yet). Otherwise it stays muted until the application releases PTT.
* *Restore serial FSK* – the same for FSK.

=== Menu Audio
This menu is only available for keyers with audio switching (micro KEYER, micro KEYER II/III, MK2R/MK2R+). Refer to the original microHam documentation for your keyer.

*Audio Switching* selects for VOICE and DIGITAL mode where the audio goes when receiving, when transmitting and when transmitting with the footswitch. The MK2R(+) has a section for each radio, which also selects the microphone and the sound card codec. The options are:

* *A* – microphone to the radio's microphone input
* *B* – sound card to the radio's line input
* *C* – sound card to the radio's microphone input
* *D* – like A + B (micro KEYER II/III)

On the micro KEYER II/III the *Audio Options* contain on air recording, the audio monitor level, the microphone selector (Auto, Front, Rear), *Sound Card PTT* and *Downstream over Footswitch*.

=== Menu Display
This menu is available for keyers with a display (micro KEYER II/III, Station Master). The first section “Display Options” allows configuration of the displays brightness, contrast and its default content.

In the second section “Display Reports” you can choose which events you want to have displayed.

=== Menu CW
This menu is only available for keyers containing a K1EL Winkey chip (all but the DIGI KEYER and the Station Master). In the first section, *Winkey*, the Winkey parameters can be configured: paddle mode (Iambic A/B, Ultimatic, Bug Keyer), PTT lead and tail, hang time, swap paddles, auto space, CT spacing, paddle watchdog, speed pot range, Farnsworth speed, DAH/DIT ratio, weighting, 1st extension, keying compensation and paddle setpoint.

Detailed description on the TODO list. Meanwhile please refer to your keyers documentation and/or to the Winkey documents at www.k1el.com.

The section *Side Tone* sets the side tone frequency (or Off). On the DIGI KEYER II and the micro KEYER II/III *Paddle Only Side Tone* limits the side tone to CW sent with the paddle.

=== Menu CW/FSK Messages
This menu is only available for keyers containing a K1EL Winkey chip. It stores the keyer’s CW and FSK message memories, 8 of each.

Enter the text for each message slot and press *Apply* to write the messages to the keyer. The *Test* button next to a slot plays the corresponding message so you can check it.

=== Menu Antenna Switching (Station Master)
These menus are only available for the Station Master / Station Master DeLuxe ([red]#experimental#). The antenna switching configuration is split across several side menu entries:

* *Switching / Load, Store* – load the current antenna switching configuration from the Station Master, or store the edited configuration back to it.
* *Switching / Settings* – general parameters: CI-V function, baud rate and address of the PA connector, the D9 serial port function and baud rate, the switch and break-before-make delays, the inhibit lead time, the Key-In options and the sequencer lead/tail times.
* *Switching / Outputs* – assign a class/function to each switch output.
* *Switching / Antennas* – manage the antenna list.
* *Switching / Virt. Rotators* – manage virtual rotators.
* *Switching / Ant. Groups* – manage antenna groups.
* *Switching / Bands* – per-band antenna assignment.

NOTE: Station Master support is experimental.

=== Menu All Parameters
A diagnostic page that lists all raw keyer parameters and their current values. They can be changed here, too. Mainly useful for troubleshooting.
