== Port Permissions

The VSP ports in `/dev/mhuxd/` are owned by the user “root” and the group “mhuxd”:

`# ls -la /dev/mhuxd/ +
drwxr-xr-x 2 root root 120 Oct 28 14:54 . +
drwxr-xr-x 20 root root 4620 Oct 28 14:54 .. +
crw-rw---- 1 root [red]#mhuxd# 246, 0 Oct 28 14:54 cat1 +
crw-rw---- 1 root [red]#mhuxd# 248, 0 Oct 28 14:54 fsk1 +
crw-rw---- 1 root [red]#mhuxd# 247, 0 Oct 28 14:54 ptt1 +
crw-rw---- 1 root [red]#mhuxd# 249, 0 Oct 28 14:54 wk`

To make these ports accessible from your account you just need to make yourself member of the “mhuxd” group. Let’s say your user id is “johndoe” you can add yourself by this command:

`sudo usermod -a -G mhuxd johndoe`

You may need to re-login for the change to take effect.

=== When installed from Ubuntu/Debian package

The package creates the user and group “mhuxd” and installs the udev rule that sets the group of the ports.

=== When installed from compiled source code

Here you have to create the user and group “mhuxd” yourself and install the udev rule from the mhuxd source directory (`debian/mhuxd.udev`) as `/usr/lib/udev/rules.d/59-mhuxd.rules`. The steps are described in <<installation>>, section “Account and Permissions”.
