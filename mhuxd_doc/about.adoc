== About

Mhuxd is a device router for microHam keyers. It runs on the Linux operating system only. Supported microHam keyers are:

* micro KEYER
* micro KEYER II
* micro KEYER III
* DIGI KEYER
* DIGI KEYER II
* MK2R & MK2R+
* CW KEYER
* Station Master / Station Master DeLuxe ([red]#experimental#)


=== Features

* Designed to run permanently in the background
* Automatically detects any supported microHam keyer, once switched on or connected to the computer
* Supports multiple keyers simultaneously
* Built-in web server to perform configuration changes via a browser
* Provides configurable virtual serial ports (VSP) and routes those to specific keyer channels (e.g. CAT, K1EL Winkey, PTT, FSK etc.)
* Provides TCP/IP network ports (IPv4 and IPv6) if desired
* Configuration of the K1EL Winkey chip, including CW/FSK message memories via browser
* Supports configuration of the microKEYER II / III displays
* RIG Mode Sync: keeps the keyer mode and the frequency known to the keyer in sync with the rig, either by decoding the CAT traffic of your applications (backend native) or through Hamlib's rigctld
* Several applications can share the rig's CAT port, each on a port of its own (backend native)
* Optionally starts and stops Hamlib's rigctld together with the keyer
* Antenna switching configuration for Station Master ([red]#experimental#)
* REST API and WebSocket interface, used by the web interface
