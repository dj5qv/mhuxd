== About

Mhuxd is a device router for microHam keyers. It runs on the Linux operating system only. Supported microHam keyers are:

* micro KEYER
* micro KEYER II
* micro KEYER III
* DIGI KEYER
* DIGI KEYER II
* MK2R & MK2R+
* CW KEYER
* Station Master / Station Master DeLuxe ([red]#experimental#)


=== Features

* automatically discovers any supported microHam keyers
* handles multiple keyers simultaneously
* graphical web front end to perform configuration changes, with live status updates
* can provide configurable virtual serial ports and routes those to specific keyer channels (e.g. CAT, K1EL Winkey etc.)
* can provide TCP/IP network ports (IPv4 and IPv6)
* configuration of the K1EL Winkey chip, including CW/FSK message memories
* configuration of the microKEYER II / III display
* keeps the keyer mode in sync with the rig mode through an external backend (rigctld)
* antenna switching configuration for Station Master ([red]#experimental#)
* REST API with a server-sent event stream, used by the web interface
